# Pocket Walk

iPhoneをズボンの前ポケットにラフに入れて使うVR歩行センサーMVPです。

## 使い方
1. iPhoneのSafariでHTTPS公開URLを開く
2. 「センサー開始」
3. 正面を向いて「今の向きを正面にする」
4. iPhoneを前ポケットに入れてその場で足踏み

## 現在の出力
- 歩行速度: 0.00〜1.00
- 身体方向: 正面から -180〜+180°
- 足踏み周期
- 動的加速度
- コンパス方位/精度

## 配置
Netlifyではこの `pocket-walk` ブランチのルートをそのまま公開します。ビルドコマンドは不要です。
